投稿URLの収集

投稿URLの収集には、専用の拡張機能 AdachiDB-Saver を使用しています。X上で表示された @adachirei0 の投稿URLを検出し、URLを正規化して足立データベースの追加APIへ送信してます。 （Xの規約的には多分まずい）

現在のXでは、タイムラインに表示される各投稿が基本的に <article> 要素として配置されています。 その中にある投稿日時の <time> 要素は、個別の投稿を開くリンクの内側にあります。 表示名や投稿本文からURLを推測せず、この日時リンクの href 属性を投稿URLの候補として取得します。 

<article>
  ...
  <a href="/adachirei0/status/投稿ID">
    <time datetime="...">投稿日時</time>
  </a>
  ...
</article>
  1. ページ内の article 要素を投稿単位として調べる。
  2. article.querySelector('time') で投稿日時の要素を探す。
  3. time.closest('a') で日時を囲むリンクまで遡る。
  4. リンクの href を読み取り、投稿URLとして正しいか検証。

Xはページ全体を読み直さずに内容を書き換えるSPAとして動作するため、 MutationObserver でタイムラインの変化を監視してます。

投稿URLを提供する

投稿追加用の POST /api/posts/add は公開されており、APIキーなしで誰でも利用できます。 足立レイの未収録投稿を見つけた場合は、その投稿URLを送信してデータ収集に協力できます。 利用方法とレスポンスはAPIドキュメントの投稿追加エンドポイントを確認してください。

追加できるのは x.com または twitter.com の @adachirei0 の投稿URLだけです。 すでに登録されているURLは重複として拒否され、短時間に大量のリクエストを送った場合はレート制限が適用されます。
